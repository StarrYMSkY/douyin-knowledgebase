# 抖音公开视频知识库

把用户指定账号、日期范围内可访问的公开口播视频整理为可追溯的证据库。优先使用脚本批处理，不逐条人工点击下载。不把作者观点当作事实，也不把机器一致当作人工确认。

## 启动与恢复

先确定账号主页、日期区间和保存目录。日期按 Asia/Shanghai，开始日包含、结束日不包含；“某日之后”是否含当天有歧义时明确说明取值。检查已有 manifest、进度、日志与进程，避免重复启动任务。

执行前阅读 [运行说明](references/operation.md)。用 `scripts/initialize.py` 将附带 runtime 复制到一个新的空工作目录；默认 CPU 单进程，可按机器配置启用 GPU。不要在 Skill 包中存放实际采集结果或登录状态。修改运行脚本前检查是否有正在运行的任务。

## 工作流与验收

1. **目录采集**：在独立浏览器配置中由用户完成登录和验证码。运行 Playwright 脚本，监听正常页面加载的作品列表并滚动翻页。不要导出 Cookie、读取其他浏览器凭据、伪造签名或绕过访问控制。平台阻断时保留进度并请求用户处理。
2. **范围与覆盖**：保存去重视频 ID、发布时间、来源 URL、目录分页终止状态。只有明确 `has_more=false` 才标为分页完成；尽可能与主页数量核对，记录获取时点。删除、私密、失效和受限条目不得算作已收集。
3. **媒体与模型**：按需下载用户有权处理的公开视频。低码率流可能没有声音；检查视频轨和音轨，必要时单独下载音频。不把下载请求成功当作媒体完整。模型用官方来源，断点下载后做 SHA-256 校验；模型包安装和权重可离线加载分别验收。
4. **双通道处理**：本地 Whisper 转写 + RapidOCR 字幕识别。先用一条样本检查中文、时间戳、字幕位置、GPU provider，再批量运行。默认每 0.5 秒抽帧，连续解码避免随机 seek 开销。裁剪会漏掉区域外字幕，必须按样本调整。
5. **证据核对**：保留独立 ASR/OCR 原文、时间戳、置信信息与差异。相似度只是对齐线索，不是准确率。数字、单位、专名、否定、引用和预测优先人工复核。OCR 未检出不自动说明视频没有字幕。
6. **知识库与汇报**：生成离线 HTML、JSON 和 SQLite 检索。总结区分作者观点、引用、案例、预测和整理者概括；每条结论回链视频与秒数。只汇报实际下载数、双通道完成数和失败数，不固定套用历史任务数字。读取最终 audit 后才声称处理完成，不能声称全部经过人工听审。

## 关键边界

- 当前包主要在 Windows + Python 3.12 上验证。CPU 为便携默认；CUDA ASR / DirectML OCR 需实际验证，不能假定任意 GPU 都可用。
- 采用有限重试和断点续跑；连续阻断时停止，不无限刷新站点。付费服务、持续监控、上传素材或公开发布知识库需要另行授权。
- 上传 Skill 时使用明确文件白名单，不提交 `.capture-browser`、Cookie、Token、媒体、签名 URL、转写全文、个人配置、模型权重或运行日志。
- 发布前运行 `scripts/test_runtime.py`，检查占位参数、历史账号和本机绝对路径已移除。测试通过不代表抖音接口永远稳定，网站结构变化需要重新验证。
